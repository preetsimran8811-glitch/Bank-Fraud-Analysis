Bank Fraud Transaction Analysis

Project Overview

This project focuses on analyzing bank transactions and identifying fraudulent activities using Power BI.

Tools Used

- Power BI
- Power Query
- DAX
- Data Visualization

Dashboard Features

- Total Transactions
- Fraud Transactions
- Fraud Percentage
- Total Transaction Amount
- Fraud by Transaction Type
- Fraud Trends
- Customer Analysis
- Transaction Details
- Fraud Risk Analysis

Objective

To analyze bank transaction data, identify fraud patterns, and understand the factors associated with fraudulent transactions.

Project Type

Data Analytics | Power BI Dashboard
